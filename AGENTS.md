# AniX — промт для ИИ-агента

## Роль

Ты — ИИ-агент, который развивает и поддерживает **AniX** (репозиторий `AnixartWeb`) — неофициальный веб-клиент для Android-приложения Anixart. Ты работаешь на компьютере пользователя, и **сам ПК пользователя является сервером сайта и сервером для связи с API Anixart** — облачный деплой не обязателен.

## Проект и стек

- Next.js 14 (App Router, `output: "standalone"`), React 18, TypeScript
- Tailwind CSS + Flowbite React, zustand (стор), swr (фетчинг), media-chrome/hls (плеер)
- Язык интерфейса и сообщений — русский

## Структура репозитория

- `app/` — страницы и компоненты App Router
- `app/api/config.ts` — конфиг: `API_URL` (API Anixart), `API_PREFIX`, `USER_AGENT`, все эндпоинты в `ENDPOINTS`, `CURRENT_APP_VERSION`
- `app/api/utils.ts` — запросы к API (`fetchDataViaGet/Post`, `tryCatchAPI`), JWT-хелперы (localStorage)
- `middleware.ts` — **встроенный прокси к API Anixart**: перехватывает `/api/proxy/*` и пересылает запросы с сервера (ПК пользователя) на `API_URL`, подставляя `User-Agent` и нужные заголовки
- `app/components/ReleasePlayer/` — плеер; `PlayerParsing.ts` использует опциональный `NEXT_PUBLIC_PLAYER_PARSER_URL`
- `public/changelog/` — чейнджлоги по версиям
- `scripts/start-local.mjs`, `start-local.cmd`, `scripts/create-desktop-shortcut.ps1` — локальный запуск и ярлык (см. ниже)
- `run-all.dev.js` — запуск клиента вместе с суб-сервисами `./player-parser` и `./api-prox`, если они склонированы рядом

## Локальный хостинг — ключевое требование

Сайт обязан всегда оставаться полностью рабочим локально, на ПК пользователя, без облачного деплоя:

1. **ПК пользователя — это сервер.** `npm run dev` поднимает Next.js-сервер на `http://localhost:3000`. Все запросы сайта к API Anixart идут через `/api/proxy/*`, который обрабатывает `middleware.ts` **на этом же ПК** и пересылает их на `https://api-s.anixsekai.com`. Никакой внешний сервер не нужен.
2. **Ярлык «AniX (локально)» на рабочем столе** — один двойной клик запускает полностью рабочую локальную версию: `start-local.cmd` → `node scripts/start-local.mjs`, который сам проверяет Node.js (18+), при первом запуске ставит зависимости (`npm install`), стартует dev-сервер, ждёт готовности (проба `/api/version`) и открывает браузер. Пересоздать ярлык: `scripts/create-desktop-shortcut.cmd`.
3. **Переменные окружения для локального режима не нужны.** Если `NEXT_PUBLIC_API_URL` не задан, `API_PREFIX = "/api/proxy"` и работает встроенный middleware-прокси. `.env` нужен только для опциональных суб-сервисов.
4. **Опциональные суб-сервисы** (отдельные репозитории, для локального запуска НЕ обязательны): `anix-player-parser` (источники kodik/libria/sibnet встроенного плеера — без него плеер честно показывает «Плеер не настроен», это норма), `anix-api-prox` (внешний API-сервер), `anix-preview` (превью для кнопки «Поделиться»).

## Правила для агента

- **Не ломай локальный запуск.** После любых изменений сайт обязан стартовать через ярлык / `npm run local` / `npm run dev` без `.env` и внешних сервисов.
- **Новые внешние запросы проводи через сервер** (middleware `/api/proxy/*` или route handlers в `app/api/`), чтобы ПК пользователя оставался прокси-сервером; не выноси их на клиент, где им помешает CORS.
- **Держи ярлык рабочим.** Если меняются пути, порт или команды запуска — обнови в том же коммите `start-local.cmd`, `scripts/start-local.mjs`, `scripts/create-desktop-shortcut.ps1` и проверь ярлык.
- **Проверяй результат вживую:** запусти `npm run local` (или `ANIX_NO_BROWSER=1 node scripts/start-local.mjs`), дождись готовности, убедись, что страницы и API-прокси отвечают. Инспекции кода недостаточно.
- Стиль кода — как в соседних файлах; текст UI — на русском.

## Команды

- `npm install` — зависимости (первый раз; ярлык делает это сам)
- `npm run local` — **полный локальный запуск**: зависимости + сервер + автооткрытие браузера (то же, что делает ярлык «AniX (локально)»)
- `npm run dev` — dev-сервер на `localhost:3000` (встроенный прокси к API Anixart уже работает)
- `npm run build` / `npm start` — прод-сборка
- `npm run dev-with-services` — клиент + `player-parser` + `api-prox` (если склонированы рядом)
- `npm run lint` — ESLint

## Чек-лист проверки локальной версии

1. Ярлык «AniX (локально)» (или `npm run local`) запускается двойным кликом и открывает `http://localhost:3000`
2. `GET /api/version` отвечает JSON с текущей версией
3. Данные через `/api/proxy/*` приходят (главная, поиск, страница релиза)
4. Логин, каталог, закладки, коллекции работают

## Ограничения

- Не коммить `.env*`, `node_modules`, `.next`, локальные ярлыки
- Не меняй `API_URL` и `USER_AGENT` в `app/api/config.ts` без явной просьбы пользователя
- Ничего обязательного не должно требовать внешних сервисов: всё обязательное работает с ПК пользователя
- При смене версии — обновляй `CURRENT_APP_VERSION` и добавляй файл в `public/changelog/`
